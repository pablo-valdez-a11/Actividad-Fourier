Simulación y análisis de señales con la Transformada de Fourier

Descripción

Este proyecto analiza tres señales: pulso rectangular, función escalón y señal senoidal, utilizando Python y la Transformada Rápida de Fourier (FFT).

Objetivo

Analizar las señales en el dominio del tiempo y de la frecuencia, observando sus espectros de magnitud y fase.

Herramientas utilizadas

- Python
- NumPy
- Matplotlib
- Visual Studio Code

Archivos del proyecto

- "simulacion_fourier.py": código fuente del programa.
- "resultados_fourier.png": gráfica de las señales y sus espectros.

Instalación

Ejecutar en la terminal:

"python -m pip install numpy matplotlib"

Ejecución

Ejecutar el programa con:

"python simulacion_fourier.py"

Resultados

Se generaron gráficas de tres señales y sus transformadas de Fourier para estudiar su comportamiento en el dominio de la frecuencia.
